IANA Time Zone Database, release 2026e, compiled to TZif files.

The Time Zone Database is in the public domain:
https://www.iana.org/time-zones  (https://data.iana.org/time-zones/tzdb/)

These are the zones listed in zone.tab, plus UTC. Adderall reads them itself,
so it behaves the same on every operating system and never needs the internet.
